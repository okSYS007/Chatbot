# Project

Telegram-бот для Tarot-группы: https://github.com/okSYS007/Chatbot, ветка `main`.

## Current stage

Случайные приветствия и новая схема карты дня реализованы и собраны в Windows EXE. Пользователь подтвердил успешную публикацию в тестовый Telegram-канал. Исходники, тесты и документация отправлены в GitHub: ветка `main`, коммит реализации `0324772`.

## Completed

- Список случайных приветствий в панели и команда `/set_welcomes`; совместимость с прежним приветствием.
- Две отдельные папки картинок и текстов. Рекурсивный поиск JPG/JPEG/PNG и TXT/DOCX, сопоставление по настраиваемым фразам в именах файлов.
- Таблица шаблонов с добавлением, изменением, удалением, подсчётом совпадений и проверкой папок без публикации.
- Случайный выбор подходящей картинки и текста того же шаблона. Неоднозначные имена и картинки без текста пропускаются.
- Ежедневное время, часовой пояс (по умолчанию Europe/Kyiv), чат/тема и переключатель публикации. Для канала ID задаётся вручную, `/daily_card_here` предназначена для групп.
- Короткий текст в подписи, длинный — полностью в нескольких сообщениях после фото. Учтены лимиты Telegram, паузы и RetryAfter.
- Отдельный журнал частей публикации; защита от дублей, перезапусков и неопределённого результата. Прежние конфиги совместимы, существующие базы сохраняются.
- Безопасная сборка в отдельную папку `outputs/`; рабочие `.env`, `config.yaml`, базы и пользовательские материалы в Git и пакет обновления не входят.
- 92 автоматических теста: 91 прошёл, 1 пропущен из-за недоступного создания symlink в Windows. Проверены GUI, совместимость на копиях двух баз/конфигов и предоставленные DOCX/PNG; исходные рабочие файлы не изменены.
- EXE запускается с `--help`; ZIP содержит только программу, шаблоны конфигурации и инструкции. Локальный пакет: `outputs/2026-10-13-card-patterns/LenormandGroupBot-update.zip`.
