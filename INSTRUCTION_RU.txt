ИНСТРУКЦИЯ ДЛЯ ЗАПУСКА БОТА
===========================

1. Первый запуск
----------------

Запустите файл:

LenormandGroupBot.exe

Если бот запускается первый раз, программа сама откроет мастер настройки.

Мастер попросит:
- токен бота из BotFather;
- отправить любое сообщение в нужную Telegram-группу;
- подтвердить найденную группу;
- указать текст приветствия.

После настройки программа создаст:

.env
config.yaml
data\
logs\

Python и зависимости устанавливать не нужно. Все уже собрано внутри exe.


2. Админ-панель
---------------

После настройки запуск LenormandGroupBot.exe открывает админ-панель.

Пока окно админ-панели открыто, бот работает.
Если закрыть окно админ-панели, бот остановится.

В панели есть:
- список пользователей, которых бот уже видел;
- репутация каждого пользователя;
- количество сообщений;
- будущий статус подписки;
- кнопка ручного начисления репутации;
- кнопка списания кристаллов.
- кнопка Реакции для настройки белого списка смайликов;
- кнопка Добавить админа для добавления Telegram user_id в админский список.

Важно: список пользователей показывает только тех, кого бот уже видел в группе.


3. Правила команд
-----------------

Команды для обычных участников начинаются с !.
Например:

!Rep
!Reputation

Команды только для админов начинаются с /.
Например:

/health
/toprep
/rep 123456789
/set_welcome Привет, {name}! Добро пожаловать.
/spend_rep 123456789 20 free_reading
/rep_reactions
/rep_reaction_add 👍
/rep_reaction_remove 🔥

Админы могут использовать и команды с !, и команды с /.
Все ответы бота в Telegram написаны на русском языке.

При запуске бот пытается автоматически добавить администраторов Telegram-группы в admins.user_ids.
Если нужно добавить человека вручную, выберите его в админ-панели и нажмите Добавить админа.
Если человека еще нет в списке пользователей, кнопка попросит ввести Telegram user_id.


4. Приветствие новых участников
-------------------------------

Бот приветствует новых участников текстом.

Если бот был выключен, он сможет обработать вступления, которые Telegram еще хранит в очереди updates. Обычно это ограниченное время, поэтому для надежной работы бот лучше держать запущенным.

Изменить приветствие можно в Telegram-группе командой:

/set_welcome Привет, {name}! Добро пожаловать в группу.

Проверить приветствие:

/test_welcome

Переменные для текста:

{name}     - имя пользователя
{username} - username или имя, если username нет
{user_id}  - Telegram ID пользователя
{group}    - название группы

Пример:

/set_welcome Привет, {name}! Добро пожаловать в наш круг Ленорман.


5. Репутация
------------

Репутацию повышают только реакции админа из списка admins.user_ids в config.yaml.

1 репутационный лайк = 1 очко репутации.

Если админ убрал засчитанную реакцию, бот снимает это 1 очко обратно.

Автором сообщения может быть любой участник.
Важно только то, что реакцию поставил админ.

Если обычный участник поставит реакцию, репутация не изменится.

Какие реакции засчитываются, указано в config.yaml:

reputation:
  admin_only: true
  points_per_admin_reaction: 1
  positive_reactions:
    - "👍"
    - "❤️"
    - "🔥"

Этот список можно менять без редактирования кода:
- через кнопку Реакции в админ-панели;
- через Telegram-команды /rep_reactions, /rep_reaction_add, /rep_reaction_remove.

Примеры:

/rep_reactions
/rep_reaction_add 🌟
/rep_reaction_remove 🔥

Посмотреть свою репутацию может любой участник группы:

!Rep

или:

!Reputation

Посмотреть топ репутации:

/toprep

Посмотреть репутацию пользователя по ID:

/rep 123456789


6. Кристаллы и списание репутации
---------------------------------

Репутация используется как "кристаллы".

Если пользователь накопил очки и хочет обменять их на скидку или услугу, админ может списать нужное количество.

Через админ-панель:
- выберите пользователя;
- нажмите Spend crystals;
- укажите количество очков.

Через Telegram-команду:

/spend_rep user_id amount reason

Пример:

/spend_rep 123456789 20 free_reading

Это спишет 20 очков репутации у пользователя 123456789.


7. Будущая подписка
-------------------

Блок подписки пока не включен.

В config.yaml уже есть задел:

subscription_bonus_enabled: false
subscription_multiplier: 2

Когда подписка будет реализована, можно будет включить режим, где репутация начисляется быстрее.
Например: 1 лайк = 2 очка репутации для пользователя с подпиской.


8. Где находятся настройки
--------------------------

Токен бота:

.env

Основные настройки:

config.yaml

В config.yaml находятся:
- chat_id группы;
- список админов;
- текст приветствия по умолчанию;
- настройки репутации;
- список админов, чьи реакции начисляют репутацию.


9. Где находится база данных
----------------------------

База данных хранится локально:

data\state.json

Резервная копия:

data\state.backup.json

Логи:

logs\bot.log

Тексты сообщений пользователей не сохраняются.


10. Очистка пользователей и репутации
------------------------------------

Если нужно очистить пользователей, сообщения, реакции и репутацию, напишите в Telegram-группе:

/reset_users CONFIRM

Команда не удаляет:
- токен;
- chat_id;
- админов;
- настройки;
- текст приветствия, установленный через /set_welcome.


11. Важно
---------

Бот должен быть добавлен в группу и иметь права администратора.

Бот работает только пока открыта админ-панель LenormandGroupBot.exe.

Если компьютер выключен или окно админ-панели закрыто, бот не сможет приветствовать новых участников и учитывать реакции за это время.


12. Безопасное обновление уже работающего EXE
------------------------------------------------

Остановите бота и закройте процесс LenormandGroupBot.exe. Сделайте датированную резервную копию всей старой папки: .env, config.yaml, весь data (включая state.backup.json и daily_cards), отдельно cards\day, пользовательскую папку изображений и logs.

Скопируйте новый LenormandGroupBot.exe в прежнюю папку, заменив только EXE. Документы и безопасные шаблоны можно обновить отдельно. Не копируйте live-базу из dev и не запускайте мастер настройки повторно.

Старые настройки и база совместимы. Карта дня по умолчанию выключена.
Случайные приветствия настраиваются кнопкой «Приветствия»: один вариант на строку.
Администратор может использовать /set_welcomes Привет, {name}! | Рады видеть, {name}!
Команда /set_welcome Текст возвращает одно приветствие. /test_welcome проверяет результат.


13. Карта дня
-------------

Настройки находятся в секции daily_card:

daily_card:
  enabled: false
  time: "09:00"
  timezone: "Europe/Kyiv"
  images_folder: "cards/images"
  texts_folder: "cards/texts"
  patterns:
    - "8 пентаклей"
    - "6 жезлов"
    - "10 кубков"
  chat_id: 0
  message_thread_id: null

В панели «Карта дня» есть две вкладки. На вкладке «Папки и шаблоны» настраиваются папки «Картинки» и «Тексты», а также таблица шаблонов с кнопками «Добавить», «Изменить», «Удалить» и «Проверить папки». На вкладке «Расписание» настраиваются время, часовой пояс, ID чата, тема и включение функции. Вложенные папки сканируются рекурсивно. Для каждой строки шаблона, например `8 пентаклей`, бот случайно выбирает картинку с этой фразой в имени, а затем случайный TXT/DOCX с той же фразой. Имена могут быть произвольными: `8 пентаклей часть души.jpg` и `8 пентаклей средина моря.docx` подходят друг к другу. Регистр не важен, пробелы и `_` считаются одинаковыми. Совпадение внутри другого слова не засчитывается; неоднозначные и неполные пары пропускаются. Имена папок не участвуют в поиске.

Изображение и документ — до 10 МБ; TXT — UTF-8 или UTF-16 с BOM; DOCX — обычный текст и абзацы без оформления, картинок и комментариев, основной XML до 4 МБ. `.doc` нужно сохранить как `.docx`. Подпись до 1024 UTF-16 code units отправляется с фото, длинный текст — после фото несколькими сообщениями до 4096 UTF-16 code units без обрезания.

Кнопка «Проверить папки» показывает количество файлов по каждому шаблону и ошибки сопоставления. Старые настройки с одним `folder` продолжают работать до сохранения новых настроек. База и пользовательские данные при обновлении не перезаписываются.

/daily_card_here — сохранить целевой чат и тему; команда выключает функцию до включения в GUI.
/daily_card_status — показать состояние.
/daily_card_preview — предпросмотр только в личке администратора, без журнала.
/daily_card_publish CONFIRM — ручная публикация при включённой функции, максимум один пост в сутки на чат и тему.

При позднем запуске публикуется только карта за текущую дату. При выключенном компьютере публикации не будет. Журналы находятся в data\daily_cards\<chat>_<topic-or-none>_<date>.json и содержат completed_parts и message_ids. Неполная отправка не повторяется автоматически: после сверки вручную досылайте отсутствующий текст, а если хотя бы часть дошла — журнал не сбрасывайте. При неоднозначном результате остановите бота и проверьте чат. Повторы карт между днями разрешены.


14. Разработка и сборка
-----------------------

Используйте локальную .venv-build или отдельную виртуальную среду, а PIP_CACHE_DIR и TEMP держите внутри проекта. build_exe.bat сам создаёт .venv-build и устанавливает зависимости; старый install_build_tools.bat не используйте. Артефакт появляется в outputs\<timestamp>\LenormandGroupBot. Для новой установки передаётся вся новая папка, для обновления — только EXE в прежней папке.

После сборки запустите:

.venv-build\Scripts\python.exe -B -m unittest discover -s tests -v

Для Windows в зависимостях используется tzdata. Расклады, обратная связь по ним и доступ при более чем 100 баллах отложены.
