ИНСТРУКЦИЯ ДЛЯ ЗАПУСКА БОТА
===========================

1. Первый запуск
----------------

Запустите файл:

LenormandGroupBot.exe

Если бот запускается первый раз, программа сама откроет мастер настройки.

Мастер попросит:
- токен бота из BotFather;
- отправить любое сообщение в нужную Telegram-группу;
- подтвердить найденную группу;
- указать текст приветствия.

После настройки программа создаст:

.env
config.yaml
data\
logs\

Python и зависимости устанавливать не нужно. Все уже собрано внутри exe.


2. Админ-панель
---------------

После настройки запуск LenormandGroupBot.exe открывает админ-панель.

Пока окно админ-панели открыто, бот работает.
Если закрыть окно админ-панели, бот остановится.

В панели есть:
- список пользователей, которых бот уже видел;
- репутация каждого пользователя;
- количество сообщений;
- будущий статус подписки;
- кнопка ручного начисления репутации;
- кнопка списания кристаллов.
- кнопка Реакции для настройки белого списка смайликов;
- кнопка Добавить админа для добавления Telegram user_id в админский список.

Важно: список пользователей показывает только тех, кого бот уже видел в группе.


3. Правила команд
-----------------

Команды для обычных участников начинаются с !.
Например:

!Rep
!Reputation

Команды только для админов начинаются с /.
Например:

/health
/toprep
/rep 123456789
/set_welcome Привет, {name}! Добро пожаловать.
/spend_rep 123456789 20 free_reading
/rep_reactions
/rep_reaction_add 👍
/rep_reaction_remove 🔥

Админы могут использовать и команды с !, и команды с /.
Все ответы бота в Telegram написаны на русском языке.

При запуске бот пытается автоматически добавить администраторов Telegram-группы в admins.user_ids.
Если нужно добавить человека вручную, выберите его в админ-панели и нажмите Добавить админа.
Если человека еще нет в списке пользователей, кнопка попросит ввести Telegram user_id.


4. Приветствие новых участников
-------------------------------

Бот приветствует новых участников текстом.

Если бот был выключен, он сможет обработать вступления, которые Telegram еще хранит в очереди updates. Обычно это ограниченное время, поэтому для надежной работы бот лучше держать запущенным.

Изменить приветствие можно в Telegram-группе командой:

/set_welcome Привет, {name}! Добро пожаловать в группу.

Проверить приветствие:

/test_welcome

Переменные для текста:

{name}     - имя пользователя
{username} - username или имя, если username нет
{user_id}  - Telegram ID пользователя
{group}    - название группы

Пример:

/set_welcome Привет, {name}! Добро пожаловать в наш круг Ленорман.


5. Репутация
------------

Репутацию повышают только реакции админа из списка admins.user_ids в config.yaml.

1 репутационный лайк = 1 очко репутации.

Если админ убрал засчитанную реакцию, бот снимает это 1 очко обратно.

Автором сообщения может быть любой участник.
Важно только то, что реакцию поставил админ.

Если обычный участник поставит реакцию, репутация не изменится.

Какие реакции засчитываются, указано в config.yaml:

reputation:
  admin_only: true
  points_per_admin_reaction: 1
  positive_reactions:
    - "👍"
    - "❤️"
    - "🔥"

Этот список можно менять без редактирования кода:
- через кнопку Реакции в админ-панели;
- через Telegram-команды /rep_reactions, /rep_reaction_add, /rep_reaction_remove.

Примеры:

/rep_reactions
/rep_reaction_add 🌟
/rep_reaction_remove 🔥

Посмотреть свою репутацию может любой участник группы:

!Rep

или:

!Reputation

Посмотреть топ репутации:

/toprep

Посмотреть репутацию пользователя по ID:

/rep 123456789


6. Кристаллы и списание репутации
---------------------------------

Репутация используется как "кристаллы".

Если пользователь накопил очки и хочет обменять их на скидку или услугу, админ может списать нужное количество.

Через админ-панель:
- выберите пользователя;
- нажмите Spend crystals;
- укажите количество очков.

Через Telegram-команду:

/spend_rep user_id amount reason

Пример:

/spend_rep 123456789 20 free_reading

Это спишет 20 очков репутации у пользователя 123456789.


7. Будущая подписка
-------------------

Блок подписки пока не включен.

В config.yaml уже есть задел:

subscription_bonus_enabled: false
subscription_multiplier: 2

Когда подписка будет реализована, можно будет включить режим, где репутация начисляется быстрее.
Например: 1 лайк = 2 очка репутации для пользователя с подпиской.


8. Где находятся настройки
--------------------------

Токен бота:

.env

Основные настройки:

config.yaml

В config.yaml находятся:
- chat_id группы;
- список админов;
- текст приветствия по умолчанию;
- настройки репутации;
- список админов, чьи реакции начисляют репутацию.


9. Где находится база данных
----------------------------

База данных хранится локально:

data\state.json

Резервная копия:

data\state.backup.json

Логи:

logs\bot.log

Тексты сообщений пользователей не сохраняются.


10. Очистка пользователей и репутации
------------------------------------

Если нужно очистить пользователей, сообщения, реакции и репутацию, напишите в Telegram-группе:

/reset_users CONFIRM

Команда не удаляет:
- токен;
- chat_id;
- админов;
- настройки;
- текст приветствия, установленный через /set_welcome.


11. Важно
---------

Бот должен быть добавлен в группу и иметь права администратора.

Бот работает только пока открыта админ-панель LenormandGroupBot.exe.

Если компьютер выключен или окно админ-панели закрыто, бот не сможет приветствовать новых участников и учитывать реакции за это время.
