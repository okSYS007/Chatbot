ИНСТРУКЦИЯ ДЛЯ ЗАПУСКА БОТА
===========================

1. Первый запуск
----------------

Сначала запустите файл:

LenormandGroupBot.exe

Если бот запускается первый раз, он сам откроет мастер настройки.

Мастер попросит:
- токен бота из BotFather;
- отправить любое сообщение в нужную Telegram-группу;
- подтвердить найденную группу;
- указать текст приветствия.

После настройки бот сам создаст нужные файлы и папки:

.env
config.yaml
data\
logs\

Отдельно устанавливать Python или зависимости не нужно. Все нужное уже собрано внутри exe.


2. Запуск и остановка
--------------------

После настройки можно запускать бот файлом:

LenormandGroupBot.exe

Пока окно программы открыто, бот работает.
Если закрыть окно, бот остановится.

Также можно использовать файлы:

start_bot.bat - запустить бота
stop_bot.bat  - остановить бота


3. Приветствие новых участников
-------------------------------

Бот приветствует новых участников текстом.

Изменить приветствие можно прямо в Telegram-группе командой:

/set_welcome Привет, {name}! Добро пожаловать в группу.

Проверить приветствие:

/test_welcome

Переменные для текста:

{name}     - имя пользователя
{username} - username или имя, если username нет
{user_id}  - Telegram ID пользователя
{group}    - название группы

Пример:

/set_welcome Привет, {name}! Добро пожаловать в наш круг Ленорман.


4. Репутация
------------

Сейчас репутацию повышают только реакции админа или модератора репутации.

Если обычный участник поставит реакцию, репутация не изменится.

Какие реакции засчитываются, указано в файле config.yaml:

reputation:
  admin_only: true
  positive_reactions:
    - "👍"
    - "❤️"
    - "🔥"

Посмотреть топ репутации:

/toprep

Посмотреть свою репутацию:

!Rep

или:

!Reputation

Посмотреть репутацию пользователя по ID:

/rep 123456789


5. Кристаллы и списание репутации
---------------------------------

Репутация используется как "кристаллы".

Если пользователь накопил очки и хочет обменять их на скидку или услугу, админ может списать нужное количество.

Команда админа:

/spend_rep user_id amount reason

Пример:

/spend_rep 123456789 20 free_reading

Это спишет 20 очков репутации у пользователя 123456789.


6. Будущая подписка
-------------------

Блок подписки пока не включен.

В config.yaml уже есть задел:

subscription_bonus_enabled: false
subscription_multiplier: 2

Когда подписка будет реализована, можно будет включить режим, где репутация начисляется быстрее.
Например: 1 лайк = 2 очка репутации для пользователя с подпиской.


7. Где находятся настройки
--------------------------

Токен бота:

.env

Основные настройки:

config.yaml

В config.yaml находятся:
- chat_id группы;
- список админов;
- текст приветствия по умолчанию;
- настройки репутации;
- список модераторов репутации.


8. Где находится база данных
----------------------------

База данных хранится локально в JSON-файле:

data\state.json

Резервная копия:

data\state.backup.json

Логи:

logs\bot.log

Тексты сообщений пользователей не сохраняются.


9. Очистка пользователей и репутации
------------------------------------

Если нужно очистить пользователей, сообщения, реакции и репутацию, напишите в Telegram-группе:

/reset_users CONFIRM

Команда не удаляет:
- токен;
- chat_id;
- админов;
- настройки;
- текст приветствия, установленный через /set_welcome.


10. Важно
--------

Бот должен быть добавлен в группу и иметь права администратора.

Бот работает только пока запущен LenormandGroupBot.exe.

Если компьютер выключен или окно бота закрыто, бот не сможет приветствовать новых участников и учитывать реакции за это время.
