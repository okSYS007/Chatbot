# Папки карт дня

Используйте две папки: одну для изображений, вторую для текстов. В каждой можно создавать вложенные папки и использовать произвольные имена файлов. Например:

```text
cards/
  images/
    8 пентаклей часть души.jpg
  texts/
    8 пентаклей средина моря.docx
```

В настройках добавьте шаблон `8 пентаклей`. Бот случайно выбирает картинку, находит шаблон в её имени и затем случайно выбирает TXT/DOCX с тем же шаблоном. Регистр не важен, пробелы и `_` считаются одинаковыми. Совпадение должно быть отдельной фразой, поэтому шаблон `8` не совпадает с `18`. Несовпадающие и неоднозначные файлы пропускаются; имена папок в поиске не учитываются.

Изображение должно быть не более 10 MB. TXT поддерживает UTF-8 или UTF-16 с BOM и размер до 10 MB. DOCX поддерживает обычный текст и абзацы без оформления, картинок и комментариев; основной XML — до 4 MB, файл — до 10 MB. Старый `.doc` не поддерживается: сохраните его как `.docx`.

Короткий текст помещается в подпись к фото до 1024 UTF-16 code units. Длинный текст отправляется после фото несколькими сообщениями до 4096 UTF-16 code units каждое. Текст не обрезается.

В GUI на вкладке «Папки и шаблоны» настройте две папки и таблицу шаблонов кнопками «Добавить», «Изменить», «Удалить» и «Проверить папки». На вкладке «Расписание» настройте время, часовой пояс, чат, тему и `enabled`. По умолчанию часовой пояс `Europe/Kyiv`, функция выключена.

Журнал публикации хранит `completed_parts` и `message_ids`. Неполная отправка не повторяется автоматически. После сверки вручную досылайте отсутствующий текст; если хотя бы часть дошла, журнал не сбрасывайте.
