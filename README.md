# LenormandGroupBot

Готовый бот для Telegram-группы: приветствие новых участников, репутация по админским реакциям, кристаллы и локальная JSON-база.

## Для заказчика

Запустить:

```text
LenormandGroupBot.exe
```

При первом запуске exe откроет мастер настройки. После настройки exe открывает админ-панель.

Пока админ-панель открыта, бот работает. Закрытие панели останавливает бота.

Подробная инструкция:

```text
INSTRUCTION_RU.txt
```

## Основная логика

- Новые участники получают приветствие.
- Текст приветствия меняется командой `/set_welcome`.
- Репутацию повышают только реакции админа из списка `admins.user_ids`.
- `1 репутационный лайк = 1 очко`.
- Если админ убрал засчитанную реакцию, бот снимает это 1 очко обратно.
- Автором сообщения может быть любой участник; важно только то, что реакцию поставил админ.
- Белый список репутационных реакций хранится в `config.yaml` в поле `reputation.positive_reactions`.
- Любой участник может написать `!Rep` или `!Reputation`, чтобы увидеть свою репутацию.
- Админ может списать очки как кристаллы через панель или `/spend_rep user_id amount reason`.
- Блок подписки пока выключен, но в конфиге есть задел `subscription_bonus_enabled` и `subscription_multiplier`.

## Команды

- Команды для обычных участников начинаются с `!`.
- Команды только для админов начинаются с `/`.
- Админы могут использовать и `!`, и `/`.
- Все ответы бота в Telegram написаны на русском языке.
- Админ может менять белый список реакций через кнопку `Реакции` в панели или командами `/rep_reactions`, `/rep_reaction_add`, `/rep_reaction_remove`.
- При запуске бот автоматически добавляет администраторов Telegram-группы в `admins.user_ids`, если может получить этот список через Telegram API.
- В админ-панели кнопка `Добавить админа` добавляет выбранного пользователя или введенный Telegram user_id в `admins.user_ids`.

## Для разработчика

Установите Python 3.11+ и соберите новую версию:

```text
build_exe.bat
```

Готовая папка появится здесь:

```text
outputs\<дата-время>\LenormandGroupBot
```

Передавать заказчику нужно всю папку целиком только для новой установки. Для обновления уже работающего бота заменяйте только EXE в прежней папке.

## Безопасное обновление

Остановите бота и сделайте датированную резервную копию всей старой папки: `.env`, `config.yaml`, весь `data` (включая `state.backup.json` и `daily_cards`), `cards/day`, пользовательскую папку изображений и `logs`. Замените только `LenormandGroupBot.exe` в прежней папке и запустите его. Не копируйте рабочую базу из папки разработки и не запускайте мастер настройки повторно.

Старый `config.yaml` совместим: новые значения подставляются по умолчанию без перезаписи файла. Карта дня выключена, пока администратор не настроит и не включит её. Балансы, пользователи и история реакций сохраняются; обновление схемы только добавляет недостающие поля. Не удаляйте `.env` и `config.yaml`: их отсутствие запускает мастер первой настройки.

## Случайные приветствия

В панели нажмите «Приветствия» и задайте один вариант на строку. Поддерживаются `{name}`, `{username}`, `{user_id}`, `{group}`. Или отправьте администратором `/set_welcomes Привет, {name}! | Рады видеть тебя в {group}, {name}!`.

Каждому новому участнику случайно выбирается один вариант. `/test_welcome` проверяет результат; `/set_welcome Привет, {name}!` возвращает одно приветствие. Существующее приветствие из базы сохраняет приоритет перед шаблонами `welcome.texts` в YAML; заданный через панель или `/set_welcomes` список имеет наивысший приоритет. Пустой список в YAML использует прежний `welcome.text`.

## Карта дня

Настройки находятся в секции `daily_card`:

```yaml
daily_card:
  enabled: false
  time: "09:00"
  timezone: "Europe/Kyiv"
  images_folder: "cards/images"
  texts_folder: "cards/texts"
  patterns:
    - "8 пентаклей"
    - "6 жезлов"
    - "10 кубков"
  chat_id: 0
  message_thread_id: null
```

1. В панели «Карта дня» откройте вкладку «Папки и шаблоны», выберите папки «Картинки» и «Тексты». Вложенные папки сканируются рекурсивно.
2. В таблице добавьте фразы карт кнопкой «Добавить», например `8 пентаклей`, `6 жезлов`, `10 кубков`. Для изменения и удаления строк используйте кнопки «Изменить» и «Удалить». Фраза должна встречаться и в имени картинки, и в имени текста. Имена файлов могут быть произвольными: `8 пентаклей часть души.jpg` и `8 пентаклей средина моря.docx` подходят для одного шаблона.
3. Создайте тему «Карта дня» в Telegram и отправьте туда `/daily_card_here`. Команда администратора сохраняет чат и тему, оставляя публикацию выключенной.
4. На вкладке «Расписание» задайте ежедневное время, часовой пояс, чат, тему и включение функции. По умолчанию — 09:00, `Europe/Kyiv`; переходы на летнее время учитываются.

Бот случайно выбирает картинку, определяет подходящий шаблон по её имени и затем случайно выбирает текст только с тем же шаблоном. Сопоставление не учитывает регистр, а пробелы и `_` считаются одинаковыми. Совпадение внутри другого слова не засчитывается: `8` не подходит к `18`. Файлы с неоднозначным или отсутствующим совпадением исключаются. Если шаблоны вложены друг в друга, используется самый конкретный; при независимых совпадениях файл пропускается.

TXT допускает UTF-8 (с BOM или без него) или UTF-16 с BOM, DOCX — обычный текст и абзацы без оформления, картинок и комментариев. Размер изображения и документа — до 10 МБ, основной XML DOCX — до 4 МБ; `.doc` нужно конвертировать в `.docx`. Короткий текст становится подписью до 1024 единиц UTF-16, длинный текст после фото разбивается на сообщения до 4096 единиц UTF-16 без обрезания. Между частями поста выдерживается пауза; при ограничении Telegram бот ждёт указанное сервером время. Лимиты сверены с [Telegram Bot API](https://core.telegram.org/bots/api#sendmessage).

Кнопка «Проверить папки» показывает количество картинок и текстов по каждому шаблону и сообщает о неподходящих, неоднозначных и неполных парах. Один шаблон может использоваться снова в другой день; разовые даты и очередь папок не используются.

Старые настройки с одним `folder` продолжают работать в режиме совместимости до сохранения новых настроек. При обновлении база и пользовательские данные не перезаписываются.

Все команды ниже доступны только администраторам:

| Команда | Назначение |
| --- | --- |
| `/daily_card_here` | Запомнить текущую группу и тему; выключить публикацию до включения в панели. |
| `/daily_card_status` | Проверить настройки и состояние сегодняшней публикации. |
| `/daily_card_preview` | Отправить пример карты в личный чат администратора; расписание и журнал не меняются. |
| `/daily_card_publish CONFIRM` | Опубликовать карту за сегодня раньше расписания в настроенное место; функция должна быть включена. |

Не более одного поста в календарный день на чат и тему, включая ручную команду и перезапуски. Сами карты могут повторяться в разные дни. При позднем старте публикуется только карта за текущую дату, пропущенные дни не догоняются. Компьютер и бот должны работать; при выключенном компьютере отправки нет. После ручного редактирования YAML перезапустите бота; панель делает это сама.

Журналы: `data/daily_cards/<chat>_<topic-or-none>_<date>.json` (при другом `storage.path` — папка `daily_cards` рядом с базой). В журнале сохраняются `completed_parts` и `message_ids`; неполная отправка не повторяется автоматически. После сверки вручную досылайте отсутствующий текст; если хотя бы часть дошла, журнал не сбрасывайте. При неопределённом результате остановите бота и проверьте чат.

Расклады, обратная связь по ним и доступ при более чем 100 баллах отложены.

Для разработки используйте локальную `.venv-build` или отдельную виртуальную среду с `PIP_CACHE_DIR` и `TEMP` внутри проекта. `build_exe.bat` сам создаёт `.venv-build`; `install_build_tools.bat` не используйте. Сборка создаёт `outputs/<timestamp>/LenormandGroupBot`: всю папку передают только для новой установки, при обновлении заменяют только EXE. Тесты:

```text
.venv-build\Scripts\python.exe -B -m unittest discover -s tests -v
```

Дополнительная зависимость `tzdata` обеспечивает часовые пояса на Windows. Тесты используют отдельные временные каталоги в `work/tmp` и заглушки Telegram. Для запуска из исходников: `.venv-build\Scripts\python.exe main.py` (панель) или с `--bot-only` (без панели). Не запускайте второй экземпляр с тем же токеном и базой.

Параметры отправки в тему сверены с [документацией python-telegram-bot 22.7](https://docs.python-telegram-bot.org/en/v22.7/telegram.bot.html#telegram.Bot.send_photo).
