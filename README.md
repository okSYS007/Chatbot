# LenormandGroupBot

## Для заказчика

В папке бота есть два основных файла:

```text
start_bot.bat
stop_bot.bat
```

### 1. Первая настройка

Дважды нажмите:

```text
LenormandGroupBot.exe
```

Мастер настройки попросит:

- токен бота из BotFather;
- отправить любое сообщение в Telegram-группу, чтобы бот сам нашел `chat_id`;
- подтвердить найденную группу;
- указать текст приветствия.

После этого мастер сам создаст:

```text
.env
config.yaml
data\
logs\
```

### 2. Запуск бота

Дважды нажмите:

```text
start_bot.bat
```

Пока окно открыто, бот работает. Если окно закрыть, бот остановится.

### 3. Остановка бота

Дважды нажмите:

```text
stop_bot.bat
```

Файл остановит запущенный `LenormandGroupBot.exe`.

## Как изменить приветствие

В Telegram-группе админ пишет:

```text
/set_welcome Привет, {name}! Добро пожаловать в группу.
```

## Как работает репутация сейчас

В текущей версии репутацию повышают только реакции админа или модератора репутации.

Если обычный участник ставит реакцию, она не добавляет репутацию.

Засчитываются реакции из `config.yaml`:

```yaml
reputation:
  admin_only: true
  positive_reactions:
    - "👍"
    - "❤️"
    - "🔥"
```

Проверить приветствие:

```text
/test_welcome
```

Поддерживаемые переменные:

- `{name}` - имя пользователя;
- `{username}` - username или имя, если username нет;
- `{user_id}` - Telegram ID пользователя;
- `{group}` - название группы.

Пример:

```text
/set_welcome Привет, {name}! Добро пожаловать в наш круг Ленорман.
```

## Команды

- `/health` - состояние бота, только для админа;
- `/test_welcome` - проверить приветствие, только для админа;
- `/set_welcome текст` - изменить приветствие, только для админа;
- `/reset_users CONFIRM` - очистить пользователей, сообщения, реакции и репутацию, только для админа;
- `/spend_rep user_id amount reason` - списать репутацию/кристаллы у пользователя, только для админа;
- `/toprep` - топ репутации;
- `!Rep` или `!Reputation` - ваша репутация, видно всем в группе;
- `/rep` - ваша репутация, запасная slash-команда;
- `/rep user_id` - репутация пользователя по ID.

## Файлы данных

Данные хранятся локально:

```text
data\state.json
```

Логи:

```text
logs\bot.log
```

Тексты сообщений пользователей не сохраняются.

## Для разработчика

На чистом компьютере для подготовки сборочной среды:

```text
install_build_tools.bat
```

После доработок собрать новую версию:

```text
build_exe.bat
```

Готовая папка для передачи заказчику появится здесь:

```text
release\LenormandGroupBot
```

Передавать нужно всю папку целиком.
